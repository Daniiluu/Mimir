# ── Dependencias Python para el pipeline de voz de Mimir ─────────────────────
#
# PRERREQUISITOS DEL SISTEMA (Windows):
#   - Python >= 3.11 instalado (https://www.python.org/)
#   - Microsoft C++ Build Tools o Visual Studio Build Tools (necesario para compilar sounddevice)
#     Descargar: https://visualstudio.microsoft.com/visual-cpp-build-tools/
#   - ffmpeg en el PATH (necesario por faster-whisper para decodificar audio)
#     Instalar con: winget install Gyan.FFmpeg
#     o descargar de: https://ffmpeg.org/download.html
#
# INSTALACIÓN (ejecutar una sola vez):
#   pip install -r requirements_voz.txt
#
# PRIMERA EJECUCIÓN:
#   Los modelos Whisper (tiny ~75 MB, base ~145 MB) se descargan automáticamente
#   en la carpeta .whisper_models/ del proyecto y se reutilizan en ejecuciones posteriores.
#   El modelo XTTS-v2 (~1.8 GB) se descarga automáticamente en ~/.local/share/tts/
# ─────────────────────────────────────────────────────────────────────────────
